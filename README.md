# amitkohli.com

## Overview
Personal website and blog built with Hugo and R blogdown (https://www.amitkohli.com/). Features data science blog posts, consulting information, and personal projects with integration to Netlify for deployment.

## Features
- Hugo static site generator with lithium theme
- R blogdown integration for R Markdown posts
- Blog content with data science tutorials and projects
- "A comforting message" section
- About/Consulting pages
- Google Analytics integration
- Disqus comments
- World map of projects visualization

## Technologies
- Hugo static site generator
- R: blogdown
- Netlify deployment
- YAML configuration
- Custom layouts and themes
