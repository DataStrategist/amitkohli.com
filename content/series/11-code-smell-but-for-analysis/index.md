Developers have a shared vocabulary for code that technically works but quietly signals something is wrong underneath. Analysts don't have that. Without a name for the warning signs, every problem looks like a one-off. This video borrows the concept of code smell and applies it to spreadsheet analysis - because unnamed problems are much harder to fix than named ones.
